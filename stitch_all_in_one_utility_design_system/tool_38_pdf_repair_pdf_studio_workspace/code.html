Why do PDF files get corrupted?

Premature download disconnections, faulty storage sectors, or interrupted exports typically drop the terminal EOF byte string (`%%EOF`). Without this trailing xref pointer, standard viewers declare the document unreadable even when 95% of byte contents remain intact.
