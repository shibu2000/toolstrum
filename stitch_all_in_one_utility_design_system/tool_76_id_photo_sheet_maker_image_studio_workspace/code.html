Drugstore & Kiosk Print Tip

When printing at kiosks (Walgreens, CVS, Walmart), order as a standard 4×6 inch photo print (costing ~$0.35) instead of a $16 passport photo order. Never select "Fit to Page" to keep actual biometric scale.
