High-Throughput Machine Learning Inference on Heterogeneous Edge Acceleration Topologies

Dr. Elena Vance, Marcus Thorne, Dept. of Applied Computational Science, Institute of Advanced Photonics

Abstract—Modern embedded intelligence ecosystems demand robust parameter scheduling alongside dynamic tensor quantization. In this research monograph, we demonstrate zero-copy memory pipelines across multi-core RISC-V nodes, decreasing dynamic dispatch latency by approximately 41.8% relative to baseline synchronous paradigms.

Through deterministic kernel interleaving and asynchronous micro-DMA arbitration, energy per tensor operation scales monotonically below 0.12 picojoules per MAC operation.
